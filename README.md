# Todo App — Frontend

React frontend for the Todo Application.  
Backend repo → [todo_backend (Spring Boot)](https://github.com/Darshan-11-create/todo_backend)  
Live demo → [https://darshan-11-create.github.io/todo-app/](https://darshan-11-create.github.io/todo-app/)

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | React |
| Language | JavaScript |
| Styling | CSS |
| HTTP Client | Fetch API |
| Deployment | GitHub Pages |

---

## Features

- User registration and login
- Password reset (Forget Password flow)
- Create, complete, and delete tasks
- Responsive UI with custom navigation
- Connected to Spring Boot REST API backend

---

## Project Structure

```
frontend/
└── src/
    ├── App.js            # Root component
    ├── Login.js          # Login page
    ├── Navbar.js         # Navigation bar
    ├── Navigator.js      # Route navigation
    ├── home.js           # Main todo dashboard
    └── forgetPassword.js # Password reset flow
```
